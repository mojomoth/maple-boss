# G1 fix round 1 — 2026-11-17 (node v24.10.0, dev server http://localhost:3000)

## P1-1 Delete modal overflows horizontally at 375px for max-length nicknames

Root cause: .confirm-body is a grid with an implicit 'auto' column. An auto track grows to its items' min-content.
Under the page's word-break: keep-all, .preview's min-content is the 120px sprite plus the whole unbreakable name,
so the track grew past the dialog (356-376px). .confirm-note and .confirm-actions (width 100%) followed it, and 삭제 was clipped.
.preview-text was a second auto-track grid with the same problem, so a long name also ran past the preview tile.

Fix (pocs/app/home.css only):
  .confirm-body  + grid-template-columns: minmax(0, 1fr)   track can no longer exceed the dialog
  .preview-text  + overflow-wrap: anywhere                  long names/job text wrap inside the tile instead of widening it
  @media (max-width: 40rem): .preview padding-inline md, .sprite--preview 96px/zoom 1, .preview-text strong text-xl
                  (same pattern the card already uses at this width; keeps the 6-char Korean max name on one line at 375px)
CharacterGrid.tsx: no change needed.
