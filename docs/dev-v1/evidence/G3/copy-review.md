# G3 문구 검토 (copy review)

2026-11-17. 대상은 `pocs/` 앱에서 사용자가 보는 모든 문구다. 화면 텍스트, 버튼, 레이블, aria-label, 제목·메타데이터, placeholder, 빈 상태, 상태 메시지, API `{ error }`, 북마클릿 alert를 모두 봤다. "전"은 G3 디자인 패스가 끝난 작업 트리 기준이다.

## 기준

규칙 원문은 WebFetch로 읽었다.

- fluent-korean (github.com/snflkd/fluent-korean, `plugins/fluent-korean/output-styles/fluent-korean.md`)
  - 문장은 서술어와 종결어미로 끝낸다. 헤더와 목록은 예외다.
  - 조사와 어미를 함부로 빼지 않는다. 의미 있는 성분도 생략하지 않는다.
  - 비유어 대신 평이한 단어를 쓴다. em dash는 쓰지 않는다.
  - 고유명사와 기술 용어는 통용되는 표기를 따른다.
- no-ai-slop (github.com/petergyang/no-ai-slop, `skills/no-ai-slop/SKILL.md`)
  - 군더더기와 요약 반복을 뺀다. 과장, 콜론으로 뜸 들이기, 이모지와 서식 남발도 뺀다.
  - 구체적인 사실과 다음 행동을 쓰고, 능동태로 쓴다.
  - em dash는 짧은 글에 쓰지 않는다.
- 작업 지시 (G3)
  - 해요체로 통일한다. 같은 조건에는 문구를 하나만 쓴다.
  - 번역투, `귀하`, `~하시기 바랍니다`, 채우기용 `~할 수 있습니다`를 쓰지 않는다.
  - 화면 제목에는 화면 이름을 넣는다.
  - 게임 용어(배율, 환산, 솔플, 파티, 난이도 이름)는 플레이어가 쓰는 대로 둔다.

표의 규칙 열은 아래 약호를 쓴다.

| 약호 | 뜻 |
|---|---|
| 해요 | 합쇼체(`~입니다`, `~하세요` 지시형 안내)를 해요체로 바꿈 |
| 한문구 | 같은 조건을 화면마다 다르게 말하던 것을 하나로 맞춤 |
| 서술어 | 명사로 끝나던 문장(`등록 완료`)을 서술어로 끝냄 (fluent-korean) |
| 군더더기 | 같은 말 반복, 채우기 표현 제거 (no-ai-slop) |
| 구체 | 무엇이 안 됐는지와 다음 행동을 씀 (no-ai-slop, fluent-korean 성분 생략 금지) |
| 영어노출 | 브라우저·크롤러의 영어 원문을 한국어 문구로 바꿈 |
| 제목 | `<title>`에 화면 이름 |
| 사실 | 실제 동작과 맞게 고침 |
| 유지-원본 | 디자인 원본(`docs/drafts/*-prompt.txt`)에 있는 문구라 그대로 둠 |
| 유지 | 이미 규칙에 맞음 |

이모지와 em dash는 UI 문구에 없었고 지금도 없다. 이모지는 테스트 데이터의 캐릭터 이름 `a.b🐉`에만 있다. `귀하`와 `~하시기 바랍니다`도 없었다.
