== 3. PLAN TERMS (read 2026-11-17) ==
Render Free Postgres (https://render.com/docs/free):
  - expires 30 days after creation; then a 14-day grace period to upgrade; after that Render deletes the database and its data
    (a database created today would have expired 2026-12-17 and been deleted 2026-12-31)
  - fixed 1 GB storage; only ONE active free database per workspace; no backups of any kind; no managed connection pooling
  - Render may run maintenance / restart it at any time (unavailable meanwhile); expiry reminder emails
  - TLS (https://render.com/docs/postgresql-creating-connecting): external connections always TLS with Render-managed certificates,
    sslmode=disable rejected, docs recommend sslmode=require and do not document a CA bundle; default IP allow list 0.0.0.0/0.
    verify-full (what lib/db.ts uses) was NOT tested: no Render database of ours exists.
  - API plans: free, basic_256mb, basic_1gb, ... (paid). Regions: frankfurt, oregon, ohio, singapore, virginia.
Neon Free (https://neon.com/docs/introduction/plans), via Vercel billing plan free_v3:
  - no expiry listed; 1 GB storage per project (20 GB across free projects); 100 CU-hours per project per month
  - compute scales to zero after 5 min idle (cannot be disabled on Free; the first query after that waits for resume)
  - 6 h restore history (1 GB of changes), 1 manual snapshot, 5 GB public egress per project per month
  - Regions (https://neon.com/docs/introduction/regions): AWS us-east-1/2, us-west-2, eu-central-1, eu-west-2,
    ap-southeast-1 (Singapore), ap-southeast-2, sa-east-1. No Seoul or Tokyo.
