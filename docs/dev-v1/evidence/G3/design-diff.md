## 남은 것 (이 작업 범위 밖)

- PoC 화면 문구의 합쇼체('없습니다', '등록하세요', '구직 등록 완료', '편성 완료')는 그대로 두었다. G1 Critic 스크립트(`evidence/G1/critic-ui/scripts/b-pocs.mjs`, `l-dbl.mjs`)가 이 문장을 확인하므로 문구 검토(API-4, P2-7)에서 스크립트와 함께 바꾼다.
- 앱 화면에 Tailwind 유틸리티 클래스가 더는 없다. `globals.css`의 `@import "tailwindcss"`(preflight)를 지우면 기본 스타일이 바뀌므로 정리 단계에서 따로 확인한다.
- 개발 서버의 Next 도구 배지(N)는 `next dev`에만 있어 수정 후 캡처에서 숨겼다.
