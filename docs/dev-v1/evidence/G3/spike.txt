== PROBLEMS / FOLLOW-UPS ==
P1 /tmp PGlite is not a usable store on Vercel: data written by one request can be missing on the next (0/20 after a burst). Neon (B1) is required
   for v1; until then the "임시 저장소" notice understates it ("서버가 다시 시작되면" -> it can happen at any time).
P2 Cold start 6.3-8.6 s per new instance with PGlite (initdb + seed). Expect ~1 s with pg + Neon; recheck after B1.
P2 Function region iad1 while users are in Korea: ~0.2 s per call. When Neon is added, put the DB and the function in the same region
   (e.g. icn1/hnd1 with an Asia Neon region); latency is dominated by function<->DB once there is a DB.
P2 Protected aliases: only maple-boss-livid.vercel.app is public; use it as BASE_URL. https://maple-boss.vercel.app is another site (/ 200, /api/health 404), hence the -livid suffix.
P3 Static import of files outside pocs/ fails under Turbopack; use fs at build time for /flow.
P3 CLI READY does not mean the alias already serves the new deployment (~1 s lag).
Note: the CLI prints that the account has no 2FA; the owner can enable it at vercel.com/account/settings/authentication.
