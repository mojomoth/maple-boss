# Maple Boss 위키

원본 문서를 LLM이 요약하고 서로 이어 둔 위키다. 원본은 고치지 않고 링크로만 가리킨다. 쓰는 규칙은 [conventions](conventions.md)에 있다.

## 운영

- [conventions](conventions.md) — 페이지 이름, 원본 목록, 원본 추가·로그·점검 방법
- [log](log.md) — 날짜순 작업 기록 (추가만)

## 개념·대상

- [maplescouter](maplescouter.md) — 캐릭터 데이터 출처: API, Turnstile, `character-store` 구조, 자동 우회 금지
- [clear-rate](clear-rate.md) — `clearRate`와 배율 합 110% 규칙, 운영자 결정
- [boss-catalogue](boss-catalogue.md) — 보스 60행, 난이도, 수치·그림 출처와 신뢰도
- [party-suggestion](party-suggestion.md) — `rankParties`·`suggestParty` 동작과 화면 연결
- [deployment](deployment.md) — 저장소(D1)·캐릭터 등록(D2) 결정, 차단 B1–B3
